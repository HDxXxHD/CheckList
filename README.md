# چک‌لیست معاملات — پنل مدیریت

پنل مدیریت مدرن (الهام‌گرفته از طراحی TailAdmin) برای ثبت چک‌لیست معاملات **قبل از ورود** و **بعد از خروج** و ارائه گزارش‌های تحلیلی.
آیتم‌های چک‌لیست دقیقاً مطابق فایل `check_list_details.docx` تعریف شده‌اند.

## اجرا

نیازی به نصب ندارد. فایل `index.html` را با دوبار کلیک در Chrome / Edge / Firefox باز کنید.

- داده‌ها در حافظه همان مرورگر (localStorage) ذخیره می‌شوند.
- از بخش «تنظیمات و پشتیبان» به‌طور منظم فایل پشتیبان (JSON) بگیرید.
- برای دیدن امکانات، از داشبورد یا تنظیمات «بارگذاری داده نمونه» را بزنید.

## امکانات

| بخش | توضیح |
|---|---|
| داشبورد | شاخص‌های کلیدی، منحنی سود/زیان تجمعی، نرخ برد، معاملات باز، میزان رعایت روانشناسی |
| ثبت چک‌لیست | فرم ۳ مرحله‌ای: بررسی بازار ← روانشناسی قبل از ورود ← بعد از خروج، با اعتبارسنجی و پنل «وضعیت آمادگی ورود» |
| لیست معاملات | جستجو و فیلتر (نماد، وضعیت، نتیجه، جهت)، مشاهده، ثبت خروج، ویرایش، حذف، خروجی Excel |
| جزئیات معامله | نمایش کامل هر دو چک‌لیست، امتیاز روانشناسی، چاپ |
| حساب‌ها | ثبت حساب با نام، بروکر و مبلغ اولیه؛ موجودی فعلی (مبلغ اولیه + سود/زیان خالص)، درصد رشد و نرخ برد هر حساب. هر معامله در فرم چک‌لیست به یک حساب متصل می‌شود |
| گزارش‌ها | فیلتر بازه زمانی/نماد/جهت/تایم‌فریم، فاکتور سود، بیشترین افت سرمایه، عملکرد به تفکیک نماد، **نرخ برد بر اساس هر آیتم چک‌لیست**، اثر رعایت هر مورد روانشناسی بر نرخ برد، خروجی Excel و چاپ/PDF |
| تنظیمات | تم روشن/تیره/سیستم، مدیریت نمادها، واحد پول، پشتیبان‌گیری و بازیابی، پاک کردن داده‌های نمونه (بدون دست زدن به داده‌های واقعی) |

## تغییر آیتم‌های چک‌لیست

تمام فرم‌ها، صفحه جزئیات، خروجی Excel و تحلیل‌های گزارش از روی فایل
`src/config/checklist-schema.js` ساخته می‌شوند. برای افزودن یا ویرایش یک آیتم فقط همین فایل را تغییر دهید؛
مثلاً افزودن یک گزینه به `options` یا یک مورد جدید به `items` چک‌لیست روانشناسی.

## نکات

- «مقدار سود و زیان» به صورت عدد مثبت وارد می‌شود و علامت آن از روی «سود / زیان / سر به سر» تعیین می‌گردد؛ سوآپ با علامت خودش به نتیجه اضافه می‌شود.
- مدت زمان معامله به دقیقه ذخیره می‌شود (ورودی: روز / ساعت / دقیقه).
- در فایل ورد واژه «سودی» برای روند آمده بود که به «صعودی» اصلاح شد.
